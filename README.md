# AussieWeb

Demo website for AussieWeb, an Australian digital studio. It is plain HTML, CSS and JavaScript with no build step needed to view it. Open `index.html` in a browser.

## Pages
- Home, About Us, Services, Portfolio, How We Work, Reviews, Pricing, Package details, Start a Project, Legal, Privacy
- 8 service pages in `services/`: Website Development, Logo Design, Mobile App, Video Animation, SMM, SEO, Content Marketing, UI/UX

## Where to change things
| What | File |
|---|---|
| Colours | `css/theme.css` |
| Fonts | `css/fonts.css` (steps for adding Neue Haas Grotesk Display are inside) |
| Header, footer, menu, phone/email | `js/layout.js` |
| Prices and packages (AUD) | `js/packages.js` |
| Animations | `js/main.js`, `css/animations.css` |
| Layout and components | `css/style.css` |

## Regenerating the pages
The HTML pages are generated by `tools/build.js`, and the client logos by `tools/logos.js`. You can edit the HTML directly. If you edit the generator instead, run it again from the project folder. Running it overwrites the HTML files.

```
node tools/build.js .
node tools/logos.js .
```

## Before launch
This is a demo. The following content is placeholder:
- Reviews, client names, team members and stats are made up. The photos in `assets/avatars/` are Unsplash stock photos. Replace them with real, consented client photos and testimonials, because fake reviews breach Australian Consumer Law.
- The client logos in `assets/logos/` are for fictional brands.
- Phone, email and address are dummy values. Change them in `js/layout.js` and `contact.html`.
- The contact form only shows a thank-you message. Connect it to Formspree or a backend.
- The Legal and Privacy pages are templates. Have them reviewed by a lawyer.

GSAP, Lenis and Google Fonts load from CDNs, so the site needs internet access.
